# Касса

Личное приложение для учёта смен, денег и кредитов. Всё хранится на вашем устройстве (IndexedDB), без серверов и аккаунтов.

- Календарь смен со статусами; статус запоминает ставку и время, чаевые вводятся каждый раз
- Доходы и расходы, кредиты и платежи, резерв «Деньги на платежи», цели, заметки
- Отчёты в CSV и PDF, резервные копии в JSON
- Настройки оформления: цвета, фон, скругление, размер текста, порядок блоков главной
- Устанавливается как приложение (PWA) и работает без интернета

## Установка на телефон

1. Откройте адрес сайта (GitHub Pages) в Safari на iPhone или в Chrome на Android.
2. iPhone: «Поделиться» → «На экран „Домой“». Android: меню ⋮ → «Установить приложение».

Напоминания о платежах показываются, пока приложение открыто. Фоновых push-уведомлений нет — для них нужен сервер.
Данные не синхронизируются между устройствами: переносите их через «Настройки» → резервная копия.

## Разработка

```bash
npm install
npm run dev          # локально
npm run build:pages  # сборка в docs/ для GitHub Pages
```

GitHub Pages: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/docs`.
